# Docker Practice

This folder contains my Docker practice labs and exercises.

## Topics Covered

- Dockerfile
- Docker Images and Containers
- Docker Volumes
- WORKDIR
- Docker Compose
- Docker Compose with .NET and MySQL
- Multi-stage Docker Builds

## Labs

| Folder | Topic |
|---|---|
| `dockerfile-demo` | Dockerfile basics |
| `docker-volume` | Docker volumes |
| `workdir-demo` | Docker WORKDIR |
| `docker-compose-demo` | Docker Compose basics |
| `compose-mysql-demo` | Docker Compose + .NET + MySQL |
| `node-multi-stage` | Multi-stage Docker build |

## Goal

The goal of these labs is to understand Docker concepts through hands-on practice.
