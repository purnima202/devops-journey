# Tutorial 1 – Introduction to Infrastructure as Code

## Overview
Learned the fundamentals of Infrastructure as Code (IaC) and how Terraform helps automate infrastructure management.

## Key Learnings
- Infrastructure as Code means managing infrastructure using configuration files.
- Terraform is an open-source IaC tool developed by HashiCorp.
- Terraform automates the creation and management of cloud resources.
- Terraform supports multiple cloud providers, including AWS.
- Terraform workflow: Write, Init, Plan, Apply.
