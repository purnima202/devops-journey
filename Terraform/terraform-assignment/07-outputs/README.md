# Tutorial 7 – Query Data with Outputs

## Objective
Learn how to retrieve and display infrastructure information using Terraform outputs.

## Files
- main.tf – Defines AWS provider, Ubuntu AMI lookup and EC2 instance.
- outputs.tf – Defines output values for EC2 details.

## Key Learning
Terraform outputs display useful information about created infrastructure, such as instance ID, public IP and AMI ID.

## Commands Practiced
- terraform init
- terraform plan
- terraform apply
- terraform output
- terraform destroy
