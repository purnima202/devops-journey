# Tutorial 3 – Build Infrastructure

## Objective
Learn how to provision AWS infrastructure using Terraform.

## Key Learning
Terraform uses provider and resource blocks to create and manage cloud infrastructure.

## Practical Work
- Configured AWS provider.
- Retrieved the latest Ubuntu AMI using a data source.
- Created an EC2 instance using Terraform.
- Verified the resource using terraform state list.
- Verified the EC2 instance in AWS Console.
