# Tutorial 6 – Define Input Variables

## Objective
Learn how to use input variables in Terraform.

## Files
- `main.tf` – Defines AWS provider and EC2 instance.
- `variables.tf` – Defines the instance_name variable.

## Key Learning
Input variables make Terraform configurations reusable and flexible. Instead of hardcoding values, we can pass them through variables.

## Commands Practiced
- terraform init
- terraform plan
- terraform apply
- terraform destroy
