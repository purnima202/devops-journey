# Ansible Automation

This directory contains hands-on Ansible projects and assignments focused on configuration management, server automation, and application deployment.

## Projects

### 1. Server Setup
Automating server configuration using Ansible roles, tasks, handlers, and Jinja2 templates.

Directory: `server-setup/`

### 2. Assignment 1 – Ansible Inventory & Variables
Automating Node.js application deployment on an AWS EC2 instance using Ansible inventory and variables.

Directory: `assignment-1/`

### 3. Assignment 2 – Terraform + Ansible Integration
Automating AWS EC2 infrastructure provisioning using Terraform and deploying a Node.js application using Ansible.

Directory: `assignment-2/`

## Technologies Used

- Ansible
- Terraform
- AWS EC2
- Ubuntu Linux
- Node.js
- Git

## Learning Objectives

- Server configuration management
- Ansible inventory and variables
- Playbooks and automation
- Infrastructure as Code
- Terraform and Ansible integration
- Automated application deployment
